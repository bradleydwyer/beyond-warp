# Reference audio

`beyond-reference.m4a` contains the 4.963-second sound excerpt from the user-selected [Star Trek Beyond warp reference clip](https://www.youtube.com/watch?v=gCCYWTAA2wQ), retrieved on 2026-10-17. It is the original stereo audio, converted from Opus to AAC, trimmed to the video duration, and given a fixed 10 dB gain to make the quiet source audible; it is not synthesised.
